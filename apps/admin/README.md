# 新版管理端（v2-admin）

这是新版管理端界面。当前本地集成方式：

1. 重写后端运行在 `http://127.0.0.1:3003`。
2. 新版管理端运行在 `http://127.0.0.1:3002`。
3. 浏览器只访问 `3002`；`/api/*` 由 Next.js 代理到重写后端，因此登录 Cookie、权限检查和数据库写入仍由权威后端负责。

```bash
# 终端一：重写后端
cd /Users/aaaa/Desktop/data-statistics-private-main55555
npm run dev -- -p 3003

# 终端二：新版管理端
cd /Users/aaaa/Desktop/data-statistics-v2-admin
BACKEND_ORIGIN=http://127.0.0.1:3003 npm run dev -- -p 3002
```

当前已经接入真实后端的页面：

- 登录、退出、修改密码；
- 组长的真实组员、岗位和接粉/炒群配对；
- 开通账号时岗位与配对同一事务保存，支持“待配对”和“兼任·本人承接”；
- 在办客户交接：先预览数量，再带相同数量确认；
- 部门/公司/总公司管理员的真实组织结构、开设组织单元、组长候选和组长任免/调组。

原型里尚未接真实接口的报表、通知、设备等组件仍保留在代码中作为视觉参考，但已从真实账号导航隐藏，不能把这些页面当成已上线功能。
