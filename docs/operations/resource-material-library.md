# 资源素材库

投流资源账号从左侧“素材库”维护名称、链接和视频或图片。总公司管理员在资源后台查看全部素材和对应效果；短信账号无此入口。号码导入时选定所属渠道、投手和素材，按原有真实客户数据计算转化。

每个素材可保留一个文件和一个链接。视频支持 MP4、MOV、WebM，最大 50 MiB；图片支持 JPEG、PNG、WebP、GIF，最大 10 MiB。推荐 H.264 MP4，MOV 或 WebM 的具体编码可能不能被当前浏览器解码，可下载原文件。每条不同广告内容建议新建素材，避免混合归因。素材停用后保留历史号码关联与统计。

## 文件存储与部署

文件在后端 `RESOURCE_MATERIAL_DIR` 指定的私有目录保存；未指定时使用后端工作目录下的 `storage/resource-materials`。目录不在 public 内，也不进入 Git。数据库存储随机文件键、原文件名、大小和内容类型。读取、下载和分段播放都先验证当前登录账号的渠道权限。

上线时需使用跨版本保留的绝对目录，例如 `/var/lib/data-statistics/resource-materials`，赋予应用运行账号读写权限，并与数据库一起备份。多实例部署需共享同一文件目录。仅同步 Git 或数据库不包含上传的文件。

前后端 Next 配置已允许 52 MiB 的代理请求，路由实际限制为视频 50 MiB、图片 10 MiB；如使用 Nginx，素材 API 路径也需配置 `client_max_body_size 52m` 及合适上传超时。生产反向代理配置需要在上线时核对。

SQLite/PostgreSQL 新增迁移 `20261012180000_resource_material_files`，为素材表增加四个可空字段，已有名称和链接素材无需迁移内容。文件替换成功才清理旧文件；失败时清理本次新文件。停用不会删除文件。

## 验证

- 文件扩展名与实际格式签名验证；限制无 Content-Length 的上传请求。
- 视频 Range 读取和无效范围返回 416。

- 浏览器新建、编辑、上传、预览、停用、号码导入选材和统计月份传递。
