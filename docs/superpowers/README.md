# 历史设计与实施记录

此目录下的 `plans/`、`specs/` 和 `reviews/` 是按日期保存的施工记录，不是当前需求文档。

其中可能保留已经废弃的方案，例如：

- 资源部确认员工日报后才入账；
- 进群、推专家、注册和开单由岗位手填数量；
- 按美国、德国、新加坡当地时区分别统计；
- 已删除的旧单体前端页面和旧 API；
- 已被统一客户共享表替代的分岗位客户入口。

当前开发和员工操作必须先看：

1. [`当前业务规则`](../business/current-business-rules.md)
2. [`当前需求文档`](../../需求文档.md)
3. [`后端 API 生命周期`](../business/api-lifecycle.md)

只有在追查某项功能当时为什么这样设计时，才阅读本目录内的历史文件。
