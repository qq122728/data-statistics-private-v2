# 独立号码去重电报机器人

这个机器人使用自己的 SQLite 数据库，与「数据统计」网站和它的生产数据库完全分开。只接受指定电报群的人类成员发来的文件；所有返回文件也发到该群，所以群成员都能看到文件里的号码和其他列。

## 群里怎么用

1. 群管理员发送 `/base`，然后在 15 分钟内上传原始库文件。原始库可以分多次上传，机器人会保存号码、国家和其他原始列。也可以在文件说明里写 `/base`。发送 `/countries` 可以看到原始库按国家分组的数量。
2. 群成员直接上传新数据文件，机器人自动去重，再按国家分别发回 Excel。也可发送 `/check` 后上传；或发送 `/numbers` 换行粘贴号码，每行一个。
3. 如果 Excel/CSV 的号码列不是常见列名，先发送 `/column 你的列名`，再上传文件。`/last` 可以重发自己最近一次去重结果。`/count` 查看库中号码总数。

**去重规则：**一个号码在本次文件里出现两次或更多次，它的所有行都不会出现在结果里。一个号码已经在原始库里，也不会出现在结果里。只有本次文件中出现一次、且库里没有的号码才导出并进入独立号码库。其他原始列跟着这条记录保留，不合并重复号码的不同姓名或备注。没有国际区号的本地号码按“国家＋号码”比较；不同国家相同的本地数字不会互相误删。能可靠换算成国际号码时，会与带国际区号的同一个号码匹配。

例如：原始库有 A；新文件是 A、B、B、C。结果只导出 C。机器人不会删除原始库的 A。

支持 `.xlsx`、`.csv`、`.txt`。TXT 默认一行一个号码，空行会跳过。CSV 支持常见逗号、制表符、分号和竖线分隔。Excel 可有多个工作表；文件里重复的号码会跨工作表一起检查。`.xls` 旧格式需要先另存为 `.xlsx`。

也支持把“编号 / 客户电话号码 / 客户姓名 / 损失金额 / 发生欺诈的平台 / 其他客户信息 / 地址”这种**一条资料占多行**的文字直接发到群里，或保存为 TXT 上传。每个“编号”会变成 Excel 中的一行；地址等字段跨行时会保留在同一个单元格里。额外的“字段名：内容”也会成为新列。只处理文字，不识别截图图片。对于这种模板，无 `+` 的完整国际号码若能被电话号码规则明确验证，也可识别国家；否则放入「未识别国家.xlsx」。

有“国家 / 国家地区 / country”等列时优先按该列分类；没有值时，只根据明确的 `+` 或 `00` 国际区号判断。不能可靠判断的号码进入单独的「未识别国家.xlsx」。不会根据普通本地号码猜国家。国家列里常见的中文、英文名称和两字母代码会统一分类。新数据按国家各返回一个 Excel；工作表、列顺序和每行的其他值保留。公式会作为普通文本写入结果，防止打开文件时执行外来公式。

上传文件最多 20 MB、10 万数据行，输出的单个 Excel 最多 45 MB。这受 [Telegram Bot API 的文件收发限制](https://core.telegram.org/bots/api)约束；大文件需要拆分。原文件如果把超过 15 位的号码存成 Excel 数字，Excel 可能已经丢失精度；请把号码列设为文本后重新导出。

## 独立部署

1. 在 BotFather 创建**新机器人**，不要复用现有资源机器人。将它以最少权限设为指定群的管理员，这样它能收到群里的普通文件，也能核实谁有权导入原始库。机器人只处理配置的一个群。[Telegram 官方说明](https://core.telegram.org/bots/features#privacy-mode)群管理员机器人能收到群消息；[`getChatMember` 的查询保证](https://core.telegram.org/bots/api#getchatmember)也要求机器人是群管理员。
2. 把这个目录发布到 `/opt/number-dedupe-bot/current`；在服务器创建无登录权限的 `number-dedupe-bot` 用户，并在该目录创建 `.venv`：`python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`。
3. 从 `number-bot.env.example` 创建 `/etc/number-dedupe-bot.env`，填入新机器人的 Token 和指定群的负数 chat ID，文件权限设为 `0600`。不要把真实 Token、号码库或结果文件放进 Git。
4. 安装 `number-dedupe-bot.service`，启动后在指定群用小样本分别试原始库、新数据、跨国家分类和 `/last`。数据保存在 `/var/lib/number-dedupe-bot`，必须纳入独立备份；网站的备份任务不会自动包含它。

服务只需访问 Telegram API，不读写现有网站数据库，也不占用网站端口。需要停止机器人时停用这个独立服务即可。

## 本地验证

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s ../../tests/integrations -p 'test_number_dedupe_bot.py' -v
```

测试覆盖原始库比对、文件内重复号码整组排除、其他列保留、国家分文件、TXT、CSV、重试不重复入库。真实电报收发需在取得新 Token 和目标群 ID 后做验收。
