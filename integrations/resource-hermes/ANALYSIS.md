# 资源效果分析与预警（每日收工推送＋按需查询）

仅分析渠道＋完整号码＋可选小组唯一匹配到投手/短信供应方的业务记录。未归属记录排除，不输出资料缺失提醒。数据库、查询授权及三个工具白名单不变。

## 核心指标

- 所选期实际事件：回复、进群、引专家、注册、首次开单数量和续充金额。续充按各笔实际资金日期，首充不重复计开单。
- 同龄转化：接粉7日回复率/进群率；引专家7日注册转化率；接粉30日开单率；首次开单后30日人均续充金额。到期日是第7/30天，仅使用完整统计日。
- 先按渠道＋投手/供应方汇总，再按国家；不以小组拆散样本。同名不同ID的渠道分开。
- 同龄比较使用截止日前最近已经成熟的14日批次，对前14日批次（批次环比）、上月同段（月环比）、去年同段（同比）。实际数量/金额使用所选日期范围，对上月/去年同段，短月两边裁成相同天数。

## 严重预警

相对下降 >= 10%（40%变36%即达到）。率的两期样本各>=30，续充人均两期开单样本各>=10。实际数量需基准期>=10次；续充金额需基准期>=10个续充客户，两期开单客户>=10。当前降至0仍可预警，基准0或样本不足静默跳过。时间不可信的同龄比较静默跳过。无资料核对、消耗完整性或未匹配警报。

量、率、金额分别解释；不直接推断投手因果，不保证下月续充。首次开单月份的7/30/60日表现保留，实际流水与批次累计不混淆。

## 权限与运行

每日推送复用数据分析助手 /daily-report-ready 的实际到期小组和统计日，5分钟检查一次；当地下班后1小时，同一时段同一统计日合并到资源分析群。发送状态原子落盘，超时结果不明不重复发；业务数据库只读，定时任务与对话工具隔离。无连续异常状态或预算调整。只更新资源参谋桥接与人格，无数据库/网页变更。单元测试覆盖阈值边界、样本门槛、零基准、跨年和跨月、实际金额、归属范围、只读权限及Excel。独立Hermes测试不向Telegram发送消息。
