# 资源分析与预警（按需试运行）

`query_resource_report({view:"analysis", period:"month", type:"ALL"})` 返回真实流水、开单月份贡献、同龄表现、数据缺口及观察信号。已有群聊/私聊授权、只读数据库和三工具白名单保持原样。

## 口径

- 业务资金：首充按 firstDepositOn（兼容 orderedOn），续充/出金按每笔事件日期。日期非法或缺失不猜月份；无日期历史余额单列数据缺口。
- 截止日之后的流水排除；只有首充金额为正才计首次开单。日期存在但首充金额缺失的续充记录不计新开单，提示补资料。
- 客户按登记首次开单月份分为本月、上月、更早、日期缺失/矛盾；每一笔本期金额必须与分组及归属合计对平。
- 所选期间限定同一自然月。同期比较按相同月内日号，遇短月两边同时裁短。默认统计日沿用现有系统日期规则，进行中的统计日不算完整的成熟观察天。
- 同龄续充：开单当天第1天，分别完整观察7、30、60天；不成熟客户单列，分母排除。接粉转化按接粉后7天或30天事件衡量。
- 归属采用渠道＋完整号码＋可选小组唯一匹配。未归属客户纳入总体资金，不能猜投手；指定投手/国家/素材时只纳入可确认归属记录，并披露筛选限制。
- 范围仅当前启用的ADS/SMS渠道及启用小组；不能与含其他渠道的公司总业绩直接比较。SMS没有素材分析。

## 试运行预警

- 数据核对：日期不完整或先后矛盾、首充金额缺失、投手/供应方归属缺失、未匹配和跨组冲突、消耗完整性无法确认。
- 同龄观察：固定渠道、投手/供应方、国家、小组，最近14天已成熟批次与之前14天批次对比；接粉各≥30、开单各≥10，比例相对下降≥30%且绝对下降≥10个百分点才提示观察。日期缺失、未知国家或归属不能据此评优劣。
- 集中度：本期有资金事件记录≥10，前三条业务记录贡献首充＋续充≥50%时提示关注大客户依赖；跨组同号不声称独立人数。
- 业务承接异常不能直接归咎投手；回复/进群等日期漏填也可能产生变化，建议先查记录与跟进。
- 消耗完整性目前没有确认字段，故只提醒核对，不进行可靠CPA/ROI排名或成本恶化/预算升降判断。不新增未经用户确认的完整性标记。
- 本版本无连续监测状态、通知去重或定时群发，不宣称连续异常、恢复或已经发通知。用户先查看日报预览；后续指定推送时间再配置调度与告警生命周期。
